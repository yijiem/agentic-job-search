# Self-hosted typefaces

Downloaded 2026-11-14 from Google Fonts. These are the unmodified Latin subsets of DM Serif Display (normal, 400) and Nunito (normal, variable weights 200–1000). The local files avoid third-party browser font requests.

Both families are released under the SIL Open Font License 1.1; the complete family licenses are included alongside the font files. No reserved font names were changed.

Font sources:

- dm-serif-display-latin.woff2: https://fonts.gstatic.com/s/dmserifdisplay/v17/-nFnOHM81r4j6k0gjAW3mujVU2B2G_Bx0vrx52g.woff2
- nunito-latin.woff2: https://fonts.gstatic.com/s/nunito/v32/XRXV3I6Li01BKofINeaBTMnFcQ.woff2
- DM-Serif-Display-OFL.txt: https://raw.githubusercontent.com/google/fonts/main/ofl/dmserifdisplay/OFL.txt
