# Company icons

Small official employer favicons used to identify companies in Explore roles. Initially retrieved on 2026-11-14 from the official websites listed in `sources.json`, including the icon hosts those sites explicitly reference. Later additions record their own observation dates. Company marks belong to their owners. Assets are served locally; viewing a company does not contact an external logo service.

SVG assets have scripting, external references, and embedded styles removed. Unsupported or unavailable icons use the app’s initials fallback. The exact served icon files are allowlisted in `jobflow/company_logo_assets.py`; provenance files are not public assets.
